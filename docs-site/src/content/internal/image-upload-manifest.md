## Capture standard

Use the production interface where possible.

Capture at desktop width unless the page specifically explains a mobile action.

Do not include seed phrases, private wallet information, personal email addresses, unpublished contract data, browser bookmarks, or unrelated desktop content.

Keep campaign names and wallet balances suitable for public documentation.
