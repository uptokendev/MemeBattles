Fee Routing is where the visible fee model becomes real treasury movement.

The public fee can stay simple because the router handles the distribution behind it.

## What the router does

The router decides where the active fee envelope goes based on the current route profile and action type.

That can include creator lanes, reward lanes, and protocol lanes.

## Why this matters

Without a single routing layer, the system would become harder to audit and harder to explain.

With a single routing layer, users can understand one fee model while the platform still supports multiple downstream systems.

## What changes by profile

The destination mix can change depending on whether a user is linked, unlinked, or in an approved recruiter path.

The important public rule is this:

The platform does not bolt extra public fees on top just because a reward lane exists.
Routing happens inside the active envelope.
