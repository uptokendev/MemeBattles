Airdrops Console is the wallet facing airdrop board.

It shows the current pool, the time to the next drop window, and recent winner records.

## What to read first

Start with three signals:

- current prize pool
- next drop countdown
- previous winners

That tells the user whether the airdrop lane is active and what just paid out.

## What the page is for

Use it to:

- track the current airdrop cycle
- inspect recent payout history
- see whether the active chain is showing BNB or SOL language
- confirm that the wallet is reading the right reward surface

## Chain note

BNB airdrop tooling is fielded.
Solana parity is still pending.

Do not tell users that a visible Solana label means the same payout rail exists there today.

## Good operating rule

Treat this page as a status board, not as a promise board.

A visible countdown or winner card helps users understand the cycle. Final eligibility still depends on the live reward rules and the published result set.
