title: Settings Console

---

Settings Console is the private service panel for the connected wallet.

Use it to keep the operator identity clean and current.

## Main controls

- edit display name and bio
- upload or replace avatar
- verify the active wallet
- check the active chain
- review notifications
- jump back to public profile or create flow

## Chain discipline

Always confirm the active chain before you act.

If the wrong network is connected, switch first. Do not approve a wallet action just because the page is open.

## Notifications

Notifications are for command traffic such as:

- launch alerts
- Prepare updates
- community activity
- page links back into the correct flow

Mark them read after action is complete, not before.

## Public versus private

Profile text can be public.
Notification state, wallet checks, and management controls remain private.
