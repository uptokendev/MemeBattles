title: Settings Console
description: How profile editing, wallet chain checks, and notifications work inside Command Center.
---

Settings Console is the private service panel for the connected wallet.

This is where you keep the account identity, wallet context, and notification settings in good order.

## Main controls

- edit display name and bio
- upload or replace avatar
- verify the active wallet
- confirm the active chain
- review notifications
- move back to profile or create flow

## Chain check

Always confirm the active chain before you approve any wallet action.

If the wrong network is connected, switch first. Do not continue just because the page is open and ready.

## Notifications

Notifications carry the traffic that points you back into the right flow, such as:

- launch alerts
- Prepare updates
- community activity
- direct page links for follow up

Mark them read after the action is complete.

## Public and private split

Profile text can be public.
Wallet checks, notifications, and account controls stay private.
